App Title: Mix Max

App Short Description:
Stop guessing, start optimizing. Mix Max uses Bayesian optimization to mathematically find the best combination of variables — whether you're perfecting a cocktail recipe or fine-tuning a complex process.

App Main Features:
- Create and manage experiments with custom parameter sets
- Define parameter ranges, types, and constraints for each experiment
- Let Bayesian optimization intelligently suggest the next experiment run to maximize information gain
- Log and track results across all runs
- Automatically surface the best-performing parameter combination based on real outputs

App Long Description:
Ever wonder what the perfect ratio of ingredients makes the best cocktail? Or which combination of settings produces the best outcome in whatever you're working on? Mix Max takes the guesswork out of it — giving anyone a mathematical, systematic way to find the best result from a set of variables.

**The Flow**

1. **Create an Experiment**
   Start by defining an experiment — give it a name and the output you want to maximize or minimize (e.g. taste score, efficiency, performance). It could be as everyday as "best homemade cocktail" or as technical as a manufacturing yield.

2. **Define Parameters**
   List all the parameters that influence your experiment. Set the type (continuous, discrete, categorical), the range of valid values, and any constraints. These are the knobs Mix Max will learn to tune.

3. **Run with Bayesian Optimization**
   Instead of testing parameter combinations at random, Mix Max uses Bayesian optimization to intelligently choose which combination to try next. Each run is selected to give the most new information about the parameter space — converging toward the optimum in far fewer trials than brute-force or grid search.

4. **Log Your Results**
   After each run, record the output. Mix Max builds a probabilistic model of how your parameters affect the outcome, getting smarter with every data point.

5. **Find the Best Combination**
   Once you've run enough experiments, Mix Max presents the best combination of parameters discovered — the mix that maximizes (or minimizes) your target metric across all recorded runs.

**Who It's For**
Mix Max is for everyone. You don't need a science degree to use it. If you've ever wanted to know "what's the best possible version of this?" — whether that's a drink recipe, a workout routine, a cooking technique, a product formula, or an engineering process — Mix Max gives you a structured, mathematical way to find the answer. Experiment smarter, not harder.
